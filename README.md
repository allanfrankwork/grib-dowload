# Grib download

Demonstrates how to do partial downloads for [GRIB](https://en.wikipedia.org/wiki/GRIB) v1 or v2 files using [wgrib](https://github.com/NOAA-EMC/wgrib2) style index files in Python.

Inspired by similar tools:
- [Fast Downloading GRIB — NOAA CPC](https://www.cpc.ncep.noaa.gov/products/tools/fast_downloading_grib.html)
- [How GRIB subsetting works in Herbie](https://herbie.readthedocs.io/en/latest/user_guide/background/grib2.html#how-grib-subsetting-works-in-herbie)

Tested with [DMI](https://www.dmi.dk/frie-data) opendata, but should work with other grib distribution services.
